## Estructura de cada vídeo

```
videos/NN_nombre/
  miniatura.png            1280x720, para YouTube
  guion.md                 guion completo + título, descripción y etiquetas
  voz/voz_completa.mp3     narración entera (0,7 s de pausa entre escenas)
  voz/escena_XX.mp3        narración de cada escena
  voz/tiempos.csv          en qué segundo empieza cada escena en voz_completa.mp3
  imagenes/escena_XX.png   fotograma final de cada escena (1920x1080)

```

**Cómo montarlo rápido:** pon `voz_completa.mp3` en la línea de tiempo; en cada inicio de escena (ver `tiempos.csv`) coloca `animaciones/escena_XX.mp4` y, cuando acabe, alarga con `imagenes/escena_XX.png` hasta la siguiente escena. Añade música sin copyright y listo.
